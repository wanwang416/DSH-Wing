## 二、逐项实现与"旧实现会红"依据

### G7 · 合批成员 messageId 进去重表
- 修法：`index.ts` onFlush 投递合并事件前，**除批尾外逐条 `dedupe.add(item.messageId)`**。
- **批尾豁免（施工中一度写错，已修正并复现留证）**：合并事件 `message_id = last.messageId`，马上要过 dispatcher 去重闸——若连批尾一起 add，合并事件被 `isDuplicate` 拦下，**整批丢失**。此冲突由最小复现测试证实（`handleInbound calls: 0`）。批尾 id 的去重位由 dispatcher 首过闸时自占，重投批尾 id 同样被拦 → **G7 防重投目标不变**，且不损 M22（合批窗口内不占位，重投会再进合批不丢）。
- 旧实现会红：批次成员重投 `isDuplicate=false` → 重复执行。
- 用例：`tests/inbound/stage6c1-g7.test.ts`（重投拦截 + M22 不回归）、`stage6c1.test.ts` G7 两条件（flush 保留全部成员 / 满员不回归）。

### G8 · turn-supervisor 双向（活动刷新模型）
- **触发条件定义（先写清再实现）**：**"活跃" = 收到任意 turn 事件（chunk/thinking/assistant message/tool call/tool result），每次事件重新 `arm(chatId)`**；**"挂死" = arm 后持续 `timeoutMs`（600s 默认）无任何新事件**；**"解锁" = onTimeout → M41 先 cancel 后 dispose 兜底**。`disarm` 唯一发生在 `onTurnEnd`。
- 改动：`experience.ts` 四处——`onAssistantMessage` 由 **disarm 改为 arm**（旧模型"首条 assistant 即解除"是挂死方向病灶：turn 后续步骤/工具挂死无人监管）；`onToolCall`/`onToolResult` 补 arm（误杀方向病灶：长工具期无 assistant 输出，turn start 后 600s 被杀，上下文错乱）。
- 双向证据（用例）：
  - 长工具不误杀：「长工具不误杀：工具活动刷新 arm → 不触发超时」（模拟每 5 分钟工具活动 × 6 次，30 分钟长任务不超时）；
  - 真挂死能解锁：「真挂死能解锁：arm 后无任何活动刷新 → 到点触发超时」（首条 assistant 后再无活动 → 700s 超时触发——旧实现 disarm 后永不触发）；
  - 生命周期收尾：「turn 结束 disarm → 不再超时」。

### M17 · 停止词词边界
- **判定方式**：中文无 `\b` 词边界，改用**「整句等值 + 轻尾语气字容错」**（`isStopPhrase`）：整句 trim 后等于短语本体，或短语后只跟轻尾语气字（吧/呀/啊/啦/哦/呢/咯/嘞/了）才算停止。
  - 命中：`停下来` `停下来吧` `别写了呀` `别说了` `不要说了啦`
  - 不命中：`别停在半路，继续说`（旧实现 includes 误杀）`发动机不要说了没事`（误杀）`先停下来再说`（带指令续句 → 交 agent）
- 两处落点同源对齐：`interrupt-classify.ts`（V4 开路径）+ `experience.ts`（V4 关路径旧 includes 链），后者直接复用 `isStopPhrase`。
- 语义不削弱：`停/停止/stop//stop/算了` 精确词全保留（用例钉死）。
- 旧实现会红：「别停在半路，继续说」旧返回 COMMAND。

### M19 · mention 判定收窄
- 修法：两处统一为 `botOpenId !== undefined && msg.mentions.includes(botOpenId)`：
  - 意图桥（index.ts L~627）：旧 `mentions.length > 0 || rawText.includes("@")` 把 @ 同事/任何 @ 字样当点名；
  - 合批跳过判定（index.ts L~822）：见 §四口径同步；
  - group-policy.ts mention 分支同步收窄（企微适配说明：`extractWecomMentions` 有 botName 时只收 @botName 精确命中，mentions 非空即 @bot，语义自洽；未配 botName 时 botOpenId 缺失 → fail-closed 不算点名）。
- **fail-closed 口径**：拿不到 botOpenId → 不算点名（宁过滤不误触发）；p2p 不走此分支不受影响；关键词策略群不受影响。
- 用例：`@别人不触发 / @机器人触发 / 无@不触发`（stage6c1.test.ts）+ group-policy.test.ts 对齐 1 条（★判定：改测试——旧用例"rawText 含 @botOpenId 字样即处理"正是本批要修的过宽语义；结构化 mentions 为准，parser 已把 @bot 剥进 mentions，真实链路不受影响）。
